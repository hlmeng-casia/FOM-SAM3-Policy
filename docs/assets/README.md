# Media Assets

- [`images/`](images/) contains the paper figures and result images used by the Project Page.
- [`videos/`](videos/) contains browser-compatible robot demonstrations and their thumbnail images.
- Media paths, titles, and playback assignments are configured in [`../project-data.js`](../project-data.js).

The public repository tracks `*-web.mp4` video files and `*_thumb.jpg` thumbnails used by the page.
