# Website fonts

Typography follows the font families used by [OpenVLA](https://openvla.github.io/static/css/index.css): Noto Sans for body copy and section headings, and Google Sans for the paper title and author information. BibTeX keeps a monospace font.

Font files are served locally with `font-display: swap`.

- `google-sans-regular.ttf`, `google-sans-semibold.ttf`: Google Sans, weights 400 and 600, supplied by the [Google Fonts CSS API](https://fonts.googleapis.com/css?family=Google+Sans:400,600&display=swap). The font metadata identifies Copyright 2025 The Google Sans Project Authors. The upstream SIL Open Font License is included as `google-sans-OFL.txt`, from [the Google Sans repository](https://github.com/googlefonts/googlesans/blob/main/OFL.txt).
- `noto-sans-latin.woff2`, `noto-sans-latin-italic.woff2`: Noto Sans Latin subset, variable weights 400–800, supplied by the [Google Fonts CSS API](https://fonts.googleapis.com/css2?family=Noto+Sans:ital,wght@0,400..800;1,400..800&display=swap). Copyright 2022 The Noto Project Authors. The SIL Open Font License is included as `noto-sans-OFL.txt`, from [Google Fonts](https://github.com/google/fonts/blob/main/ofl/notosans/OFL.txt).

The font binaries are unmodified downloads.
